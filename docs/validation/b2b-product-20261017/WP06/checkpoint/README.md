- `membership/access.ts`: `authorizeExportIdentity(db, actorId, organizationId, sessionId, {contractHeader, whiteLabel, domain})` verifies the current session, selected membership, live domain generation and binding, migration readiness and product activation, inside the caller's transaction. Returns the frozen identity context with export capability only. It grants no operational access. `inactiveAccess(identity, productRole)` returns the frozen ProductAccess DTO, empty operational branches, export capability only. `inactiveRouteAllowed(method, canonicalPathname, organizationId, header, range)` is a deny-by-default restricted-session allowlist; HEAD/range and every operational/mutation route are denied. Authentication admission remains separate.
- `exports/index.ts`: `createPersonalExportServices({now?, b2cInvitationUrl?})` implements frozen `personalExport` and `b2cInvitation` self services. Both use the caller's identity context/transaction. No additional DTO, package or dependency was invented. Invitation is configuration only; it creates no account, cookie, billing or transfer operation.
- `exports/training.ts`: reads immutable issued routines, supplements, all accepted enrollment/occurrence/session revisions and legacy originals, scoped to the identity and selected organization. Historical/revoked branches remain in own export. No operational grant follows from that projection.
- WP11: use existing `PersonalExportSchema`, `TrainingInterchangeSchema`, `ProductAccessSchema`, `B2CInvitationSchema` from `@klisteniapp/b2b-contracts/product-v2`.
