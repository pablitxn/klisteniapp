# Base exercise catalog

The original B2C exercises, planning metadata, identifiers, source citations, starter routine and muscle descriptions, extracted without changing their content. Both products can consume these stable records while keeping ownership, prescription, billing and access rules outside the catalog.

Exports: `exercises`, `getExercise`, `muscles`, `exercisePlanning`, `starterRoutine`, `cardioActivities`, `educationNotes` and the versioned `catalogManifest`. Existing B2C paths re-export these records for compatibility. A gym catalog can reference base IDs and add its own reviewed entries without implying that a matching 3D movement exists.
